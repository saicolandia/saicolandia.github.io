## TIPOS DE VARIABLES

## CUALITATIVA o CATEGORICA:

No se pueden medir numéricamente, ni hacer operaciones aritméticas con ellas. Por ejemplo, la profesión del padre, color del pelo, nombre de una persona, asignatura preferida, etc. 
Se agrupan por modalidades, por ejemplo, la variable sexo presenta  dos modalidades: femenino y masculino.

Cuantitativa discreta: sólo admite valores aislados. Se habla de elementos o datos. Por ejemplo, el número de hijas de una familia, el número de obreros en una fábrica, talla del pantalón, etc.

## CUANTITATIVA

Pueden expresarse mediante numeros y permite realizar operaciones aritmeticas. Los valores representan cantidades o magnitudes

## TIPOS DE VARIABLES

Cuantitativa continua: puede admitir cualquier valor dentro de un intervalo.

Se clasifican en intervalos o clases. Por ejemplo el peso (2.3 kg, 2.4 kg, 2.5 kg,. .. ), la altura de un objeto (1.64 m, 1.65 m, 1.66 m,. , temperaturas registradas en un observatorio o la presión sanguínea de enfermos, es decir permiten que siempre exista un valor entre dos variables.

# NIVELES DE MEDICIÓN DE LAS VARIABLES

La medición de las variables puede realizarse por medio de cuatro escalas de medición

## Nivel nominal:

- Es el nivel más básico de medición.

- Las variables en este nivel tienen categorías que son solo nombres, sin un orden específico.

- Los números asignados a las categorías son arbitrarios y solo sirven para distingulas.

- No se pueden realizar operaciones aritméticas con estos números.

## Ejemplos:

- Tipo de hogar: unipersonal, monoparental, nuclear, etc.

- Facultad en la que está inscrito un estudiante: Psicología, Filosofía, Medicina, etc.

- Área de especialización preferida: Clínica, Educacional, Jurídica, etc.

- La codificación numérica puede ser arbitraria, pero debe ser consistente.

## NIVELES DE MEDICIÓN DE LAS VARIABLES

## Nivel ordinal:

- Además de distinguir categorías, este nivel establece un orden entre ellas.

- Los números asignados reflejan la jerarquía o el orden de las categorías.

- Aunque se puede determinar que una categoría es mayor o menor que otra, no se puede cuantificar la diferencia exacta entre ellas.

- Ejemplos:

- Nivel educativo: ninguno, primario incompleto, primario completo, secundario, etc.

- Condición de pobreza: no pobre, pobre, indigente.

- Rendimiento académico: insatisfactorio, satisfactorio, bueno, muy bueno, excelente.

- Los números asignados deben respetar el orden de las categorías.

## NIVELES DE MEDICIÓN DE LAS VARIABLES

## INTERVALO

Tiene orden y las distancias entre valores son iguales, pero no tiene un cero absoluto. Qué se puede hacer: Sumar, restar, calcular medias, desviaciones.

Ejemplos:

Temperatura en grados Celsius o Fahrenheit (0 grados no significa "ausencia" de temperatura).

Test de CI (coeficiente intelectual): un CI de 120 no significa el doble de inteligencia que uno de 60.

RAZÓN

Qué es: Como el intervalo, pero sí tiene cero absoluto (es decir, el cero significa “nada” de lo que se mide).

Podés realizar todas las operaciones matemáticas (sumar, restar, dividir, multiplicar).

Ejemplos:

Edad (una persona de 40 años tiene el doble de años que una de 20). 

ingresos, cantidad de hijos.
